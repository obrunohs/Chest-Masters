# Chest Masters

Projeto organizado para GitHub Pages + Firebase.

## Arquivos

- `index.html` — jogo dos players
- `painel-admin.html` — painel separado do admin
- `css/style.css` — visual do jogo e painel
- `js/firebase-config.js` — configuração Firebase já preenchida
- `js/game-data.js` — dados dos baús, martelos e cartas
- `js/game.js` — lógica do jogo
- `js/admin.js` — lógica do painel admin
- `rules/firestore.rules` — regras do Firestore

## Publicar no GitHub Pages

Suba todos os arquivos para o repositório e ative:

Settings > Pages > Deploy from branch > main > root

URLs:

- Jogo: `/index.html`
- Painel: `/painel-admin.html`
